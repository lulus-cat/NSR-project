# NSR 개인정보 경계 규칙

이 앱의 녹음에는 환자 정보가 들어 있다. 경계는 두 겹이고 서로 다르다.

## 두 개의 경계

1. **`redactForExport`** — 파일로 내보내기·공유. 사용자가 끌 수 **있다**
   (전사본은 증거라서, 신고 절차에는 원문이 필요할 수 있다). 끄더라도
   무엇이 들어 있는지는 내보내기 전에 알려준다.
2. **`redactForNetwork`** — 남의 서버로 가는 모든 것(LLM 포함). **끌 수 없다.**
   남의 서버로 간 것은 되돌릴 수 없다. 새 네트워크 기능은 예외 없이
   이 함수를 거친다 — `shareWardPack` 이 이걸 우회했다가 잡힌 전례가 있다.

## 철칙

- 위치·녹음·전사본·태움 점수는 기기 밖으로 나가지 않는 것이 기본값이다.
  나가는 기능을 만들면 화면에 "나간다"고 그 자리에서 말한다.
- API 키는 `expo-secure-store` 에만. 앱 번들·설정 DB·로그에 넣지 않는다.
- 병동 사전(WardPack) 내보내기는 `scanPackForPii` 를 먼저 통과한다.
  **보고만 하고 자동 삭제하지 않는다** — 이름을 기계로 지우면 문장이 깨진다.
- 자동 삭제(보관기간)는 사용자에게 보이는 값이다. 조용히 지우면 증거가
  사라진다 — 용량 초과는 삭제가 아니라 경고다.
- 원본 전사본은 저장 시점에 가리지 않는다. 가리는 것은 **나갈 때**다.
