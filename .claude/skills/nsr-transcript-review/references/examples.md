# 판정 예시 모음

SKILL.md 의 기준을 실제 문장에 적용한 기록이다. 실제 녹음에서 확정된 것이 쌓이면 여기에
붙인다 — 문장은 가린 형태로만. 아래 첫 묶음은 사전(`misheard.ts`)과 문서(docs/02)에서 가져온
출발점이다.

## A 반복 환각

| 원문 | 제안 | 근거 | 결과 |
| --- | --- | --- | --- |
| "네 네 네 네 네 알겠습니다" | "네 알겠습니다" | 직전 12초 무음. 같은 어절 5회 | 확인 요청 (실제 "네네" 가능) |
| "확인했어요 확인했어요 확인했어요 확인했어요" | "확인했어요" | 세그먼트 끝. 4회 연속 | 확인 요청 |
| 세그먼트 3 끝 "소변량 괜찮아요" → 세그먼트 4 첫머리 "소변량 괜찮아요" | 뒤쪽 삭제 | 30초 경계에서 앞 문맥이 이월됨 | 자동 (경계 이월은 환각 확률 높음) |

반복이 **2회**면 잡지 않는다. "네 네" 는 사람이 실제로 그렇게 말한다.

## B 임상 어휘 부재

| 원문 | 제안 | 갈래 근거 | 문맥 근거 | 확신 |
| --- | --- | --- | --- | --- |
| "노디 먼저 드려" | 노티 | misheard 등록어 | "드려" = 보고 동사 | 높음 |
| "섹션 해주세요" | 석션 | misheard 등록어. "섹션 하다" 는 뜻이 없음 | 앞 문장 "가래 많아요" | 높음 |
| "폴리 사빕 했어요" | 폴리 삽입 | 연음. 발음형 동일 | "폴리" 옆 | 높음 |
| "세츄레이션 92" | 세추레이션(SpO2) | misheard 등록어 | 숫자 92 = 산소포화도 범위 | 높음 |
| "에비지에이 나갔어요" | ABGA | 약어 한글 읽기 | "나가다" = 검체 보냄 | 높음 |
| "카데타 빠졌대요" | 카테터 | 외래어 표기 흔들림 (0.79) | "빠지다" | 중간 → 어느 카테터인지 앞 문장 확인 |
| "석숀 두 번" | 석션 | 발음 0.84, 문턱 미만 | "두 번" 횟수 + 가래 문맥 | 중간 → 이 병동 표기 물어봄 |
| "티오티 확인" | ? | 무의미 음절. 약어 풀이 TOT 는 사전에 없음 | 앞뒤 정보 없음 | 낮음 → 질문 |

## C 순수 한글 오독

| 원문 | 제안 | 근거 | 사전 반영 |
| --- | --- | --- | --- |
| "낼 오프예요" | 내일 오프예요 | 구어 축약. 일정 문맥 | 안 함 (글자 치환 규칙만) |
| "안대요 그거" | 안 돼요 그거 | ㅐ/ㅔ 합류 + 띄어쓰기 | 안 함 |
| "갔다 놨어요" | 갖다 놨어요 | 받침 혼동. 물품 문맥 | 안 함 |
| "이붠 하셨어요" | 입원 하셨어요 | 연음. **입원은 사전어**이므로 B 로도 볼 수 있음 — 사전에 이미 있어 자동 교정됨 | 이미 있음 |

## 경계 사례 — 문맥이 가른 것

| 원문 | 자리 | 판정 |
| --- | --- | --- |
| "오다가 봤어요" | 동사 | 일반어. 교정 안 함 |
| "오다 났어요" | 명사 자리 + "나다" | 오더 (misheard). B |
| "라인 좀 봐 줘" | 앞 문장 "수액 안 들어가" | IV line. 주석만, 교정 안 함 (화자 표기 그대로) |
| "라인 서 있어" | 대기 문맥 | 일반어 |
| "디씨 났어요" 앞 문장 "내일 집에 가신대" | | D/C = 퇴원 |
| "디씨 났어요" 앞 문장 "칼륨 높아서" | | D/C = 투약 중단 |
