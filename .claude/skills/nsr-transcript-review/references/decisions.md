# 확정된 판별 기준

실제 전사본 교정 세션에서 사용자가 확정한 것만 적는다. 머리로 지어낸 기준은 넣지 않는다.
한 항목은 "이런 모양이면 이렇게 판정한다" 로 읽혀야 한다. 근거 칸에는 그 판정을 낳은
문맥을 (환자 정보 없이) 적는다.

## 원칙 (사용자가 말로 정한 것)

- **상표명은 오류가 아니다.** 병동은 성분명보다 상표명으로 부른다(큐프린=노르에피네프린,
  타조피신, 에포카인, 포스페넴). 상표명이 나오면 고치지 말고 사전에 별칭으로 넣어 학습한다.
- **사전에 없는 3~4음절이 이름 자리에 오면 이름을 의심한다.** "[이름]님" 처럼 가려지지 않은
  이름 오인식이 있었다(질문 1). 용어로 추정해 확정하지 않는다. 이름은 어떤 기록에도 옮기지 않는다.
- **병동 약어는 일반 약어집과 뜻이 다를 수 있다.** DI = 이 병동의 좌변약(약물중독 아님).
- **흔한 일반어와 겹치는 말은 규칙으로 만들지 않는다.** "시기"(식이) · "발차"(컬처)는 뜻이 갈린다.
  `misheard.ts` 가 아니라 `COMMON_WORDS` 로 보호하고 문맥으로만 판단한다. 규칙으로 만들면
  2026-09-02 의 "아니"→"아이" 사고가 되풀이된다.
- **기기는 상표명으로 부른다.** 하이플로우 기기 = 에어보(AIRVO) · 옴니옥스. 위산억제제 = 판토라인.
