# 문맥 교정 — 읽는 판을 만드는 규칙

2026-09-03 에 정해졌다. 사전 치환만 한 교정본을 사용자가 읽고 "무슨 말인지 이해를 못하겠다,
문맥이 자연스럽게 교정돼야 한다" 고 했다. 그래서 **교정의 산출물은 사람이 읽을 수 있는 판**이고,
도구의 치환은 그 앞의 보조 단계일 뿐이다. 이 문서는 Claude 가 문맥으로 직접 고칠 때의 규칙이다.

## 입력

휘스퍼 원문(`rawText`). 앱이 자동 교정한 문장은 쓰지 않는다 — 과교정 사고가 있었다(log.md 2026-09-02).
`[이름]`·`[생년월일]` 가림은 그대로 둔다. 화자 구분은 보통 없다.

## 바꾸지 않는 것

- 화자가 실제로 한 말. 은어·상표명·줄임말·사투리·군말은 그대로 ("폴리", "노티", "큐프린", "쌤").
- 문장의 순서와 개수. 합치거나 요약하거나 빼지 않는다. 문법을 다듬지 않는다.
- 가림 토큰. 이름은 어떤 경우에도 추측해 쓰지 않는다. 안 가려진 이름으로 보이면 `[이름]` 으로 바꾼다.
  전화번호·등록번호로 보이는 숫자열은 `[번호]`.
- 상표명 (decisions.md 원칙). 임상 사실을 지어내지 않는다.

## 고치는 방법

1. 앞뒤 20줄을 본다. 어느 환자·어떤 처치·어떤 수치 얘기인지 잡고 나서 낱말을 정한다.
2. 갈래를 가른다 — A 반복 · B 임상 어휘 부재 · C 순수 한글 오독.
3. 제안한 말을 넣어 문장이 되는지, 옆의 숫자·단위와 맞는지 다시 읽는다. 안 되면 바꾸지 않는다.
4. 확신 등급.
   - 높음: 한 가지로만 읽힌다 → 조용히 바꾼다.
   - 중간: 그럴듯하지만 다른 가능성이 남는다 → 바꾸고 뒤에 `(?)`. 예 `리체크(?)`
   - 낮음: 모르겠다 → 원문을 `[?원문]` 으로 남긴다. 예 `[?피리테]`
   표시는 아껴 쓴다. 문단이 표시로 뒤덮이면 읽히지 않는다. 조사·띄어쓰기·"음, 어" 정리는 표시 없이.
5. 숫자는 문맥이 확실할 때만 ("7도 3" → "37.3").
6. A 반복: 3번 이상 연달아 나오면 한 번만 남기고 ` (반복)`. 한 구간이 통째로 잡음·환각이면
   `[hh:mm:ss] (잡음·반복 구간, 내용 없음)` 한 줄. 기준: 앞뒤와 연결이 없고 같은 낱말이 되풀이되거나
   노래 가사·광고 문구처럼 병동과 무관한 문장이 이어질 때.

## 출력 A — 읽는 판 `data/reviews/<파일>.readable.md`

```
## 녹음 N (hh:mm:ss ~ hh:mm:ss)

[00:11:08] [이름] 님 라인 잡는데 끙끙거리길래 이제 보니까 항생제(?)가 17일까지인가 이렇게 돼 있길래 일단 물어봤어요. 씨라인 기준 내일 종료 예정인데요. 이제 [?피리테]를 잡아주라 그래서 일단 잡아놨습니다.

[00:10:53] (잡음·반복 구간, 내용 없음)
```

- 문단으로 묶는다. 같은 얘기가 이어지고 세그먼트 간격이 10초 안이면 한 문단. 화제가 바뀌거나 간격이 길면 새 문단.
  한 문단은 대략 6문장까지. 문단 첫머리에 첫 세그먼트의 시각 하나.
- 문장 끝에 마침표·물음표. 말투는 원래대로.
- 파일 끝에 `## 이 녹음에서 못 정한 것` — SKILL.md 의 질문 형식, 15개 이내, 투약 > 처치 > 검사 > 업무 순.

## 출력 B — 고친 목록 `data/reviews/<파일>.items.jsonl`

한 줄에 JSON 하나: `time · from · to · kind(A/B/C) · confidence(high/medium/low) · context`.
조사·띄어쓰기·군말 정리는 넣지 않는다. B 갈래는 확신이 높아도 전부 넣는다(빈도를 세야 사전에 올릴 수 있다).
중간·낮음은 갈래와 상관없이 전부. 낮음의 `to` 는 후보를 " / " 로 잇거나 빈 문자열.

## 긴 파일

녹음 단위로 나눠 병렬로 한다 (에이전트 하나가 녹음 하나). 300줄씩 끊어 읽되 앞 덩어리의 마지막 20줄을
문맥으로 갖고 간다. 출력은 이어 쓴다 — 중간에 멈춰도 앞부분이 남게. 끝나면 items 를 모아 B 갈래 빈도표를
만들고, 2번 이상 나온 것을 `data/corrections/proposed.jsonl` 에 올린다(확정은 사용자가).

## 참고 — 이미 본 오인식

사용자 확정 전의 Claude 판정은 `log.md` 세션 절에, 확정된 것은 `decisions.md` 에 있다. 문맥이 맞을 때만 쓴다.
사전에 없는 말이 곧 오인식은 아니다.
