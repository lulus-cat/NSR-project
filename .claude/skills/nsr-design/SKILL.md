# NSR 디자인 규칙

연구해서 정한 값들이다 (당근 SEED · Material 3 · KRDS 토큰 파일 실측).
감으로 바꾸지 말 것. 바꾸려면 `src/theme.ts` 의 주석과 함께 바꾼다.

## 절대 규칙

1. **색·간격·글자는 전부 `src/theme.ts` 토큰에서 온다.** 화면 파일에 리터럴
   색상·크기를 박지 않는다. 예외는 흰 글자 `#FFFFFF` (버튼·배지 위) 하나.
2. **한글 자간은 0.** 음수 자간은 받침 글자(밝·없·궤)의 획을 붙인다.
   "한글은 자간을 좁혀야 한다"는 말에는 근거가 없다 — SEED 는 자간 토큰이
   아예 없다.
3. **lineHeight 는 절대 px.** RN 은 배수를 받지 않는다. 1.4 를 넣으면 1.4px 가
   되어 줄이 겹친다. 한 줄 라벨은 1.35 배, 여러 줄 본문은 1.5 배를 계산해 정수로.
4. **16px 미만 글자는 굵게(600+).** 작은 글씨 regular + 회색은 다크에서 안 보인다.
5. **터치 목표는 최소 48dp** (`TOUCH_MIN`). 버튼·행·달력 셀 전부.
6. **다크에서 계층은 그림자가 아니라 표면 밝기.** bg < surface < surfaceAlt <
   surfaceRaised. 순검정 배경에 순백 글자를 올리지 않는다.
7. **숫자는 `TABULAR`** (tabular-nums) 를 얹는다 — 시간·용량처럼 갱신되는 값이
   흔들리면 싸 보인다.

## 화면 골격

- 모든 탭 화면은 `HeaderScreen` (색면 헤더 + 위로 물고 올라오는 패널, ShopBack
  레이아웃). `title` 은 화면 이름 또는 인사말, `hero` 는 그 화면의 대표 숫자 하나.
- 카드 안 구조: `Heading` → `Body`/`Small` → 행동(`Button`/`Row`). 카드 하나에
  주제 하나.
- 목록 행은 `Row` (label 왼쪽, value 오른쪽, 탭 가능). 구분은 `Divider`.
- 상태 표시는 `Badge` — tone 은 ok/muted/warn/danger 네 개뿐. 새 톤을 만들지
  않는다.

## 말투 (2026-09-04 사용자 확정 — 어기면 다시 쓴다)

1. **해요체로 통일.** 한 문장 안에서 섞지 않는다. 합니다체·하십시오체는 쓰지 않는다.
2. **글자 수 상한**: 버튼 8자 · 제목 20자 · 본문 한 문장 35자.
3. **한 문장에 메시지 하나.** 두 개면 `<Small>` 을 두 줄로 쪼갠다.
4. 수동태와 "~하실 수 있습니다"·"부탁드립니다"·"~해주시기 바랍니다" 금지.
5. **오류는 [무엇이 잘못됐는지] + [어떻게 하면 되는지] 두 조각을 반드시 넣는다.**
   사용자를 탓하지 않는다. 예: "열쇠가 맞지 않아요. 설정에서 다시 넣어 주세요."
6. 느낌표·이모지·말장난·유행어 금지. (예전 판의 "슝", "갓벽", "ㅠㅠ" 는 전부 걷어냈다.)
7. **개발 용어 금지** — 서버·네트워크 요청·토큰·세션·API 키는 사용자 말로 바꾼다.
   토큰/API 키 → **열쇠**, 전사 → **글자로 바꾸기**, 마스킹 → **가리기**.
   제품 이름(Docker·Wi-Fi·콜랩)은 사용자가 실제로 찾아야 하므로 그대로 둔다.
8. **버튼 라벨은 동사로 끝내고, 눌렀을 때 실제로 일어나는 일을 쓴다.**
   "확인" 처럼 뜻 없는 라벨 금지. 대화상자의 취소는 "그만두기".
9. **헤드 문구·인사말만 예외** — 신규간호사에게 재미있게 (예: "동기사랑 나라사랑",
   "바이탈보다 내 커피가 먼저"). 그래도 느낌표·이모지는 안 쓴다. 홈 화면
   `GREETINGS` 가 그 자리다.

- 기능의 한계는 숨기지 않고 그 자리에 적는다 ("안드로이드 14부터는 막힐 수 있어요").
  이 앱의 신뢰는 정직함에서 온다.
- 태움 지수는 사용자 앞에서 항상 **체온**으로 말한다 (`taeumTemperature`).
- 이 규칙은 화면 문구·오류 문구·알림에 적용된다. **코드 주석과 LLM 프롬프트는
  해당 없다** (주석은 개발자용, 프롬프트는 모델용이라 문체가 곧 동작이다).
