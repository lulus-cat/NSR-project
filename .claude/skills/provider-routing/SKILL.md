# 경로별 모델 배정과 근거

**근거 없이 배정을 바꾸지 않는다.** 아래 근거가 틀렸음을 보인 뒤에만 바꾼다.
"통일하는 게 낫지 않나"는 근거가 아니다.

## Claude 단독 경로 (구현됨)

| 단계 | 모델 | 근거 |
|---|---|---|
| 3a 추출 | claude-opus-5, effort **high** | 벤치마크상 effort high 가 긴 문서 종합에서 xhigh·max 보다 좋다 (사용자 검증). temperature 는 Opus 5 에서 제거된 파라미터 — adaptive thinking+high 가 대체 |
| 3b 조사 | **claude-fable-5-1** + 웹 검색 | 환각률이 가장 낮아 웹 조사(억지 추정 위험 최대)에 배치. **도구 강제(tool_choice any·tool)를 400 으로 막으므로** 이 자리에서는 쓰지 않는다 — 3b 는 web_search 만 달아 auto 로 돈다 |
| 4·5 | **gemini-3.8-flash** | 1M 컨텍스트·긴 입력 할증 없음·최저가 |
| 5b | claude-opus-5, high | 판단 품질 + 도구 사용 |

## GPT+Gemini 하이브리드 경로 (사양)

핵심: **두 계열의 약점이 반대 방향**이다 (AA-Omniscience: GPT-5.6 Sol 정확도
59%·환각률 92%, Gemini 3.7 Flash 55%·65%). GPT 는 기권하지 않고(재현율),
Gemini 는 기권한다(정밀도).

| 단계 | 모델 | 근거 |
|---|---|---|
| 3a 추출 | **gpt-6-astra** | 기권 안 하는 성질 = 재현율. 과잉 추출은 3v 가 거른다 |
| 3v 검증 | **gemini-3.8-flash** (기계 검증 선행) | 기권하는 성질 = 정밀도. 다른 모델 출력 검토라 자기 승인 편향 없음 |
| 3b 조사 | gemini-3.1-pro + 검색 | 모르는 걸 모른다고 말하는 성질이 웹 조사에 필수 |
| 4·5 | **gemini-3.8-flash** | 위와 같음 |
| 5b | gemini-3.1-pro | 추론력보다 기권 성질이 중요한 자리 |

**이 배분을 뒤집지 않는다.** GPT 에 검증을 맡기면 자기 출력을 무비판 승인하고,
Gemini 에 추출을 맡기면 놓친다.

## 자동 대체 금지

- 한 제공사 미연결/장애 시 **다른 모델로 자동 대체하지 않는다.** 역할 분담이
  안전성의 원천이라, 한쪽이 빠지면 설계가 무너진다. 실패로 처리하고 어느 쪽이
  없는지 표시한 뒤, 다른 경로 선택을 안내한다.
- 하이브리드는 OpenAI 와 Google 키가 **둘 다** 있어야 켜진다. Claude 단독은
  Claude 와 Gemini 키가 둘 다 있어야 켜진다.
