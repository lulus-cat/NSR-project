# 앱과 AI 의 경계 — 폰 · VPS · 대화 AI

이 문서는 0.1.7x 이후의 구조 개편을 정한다. **무엇이 어디서 돌고, 무엇이 어디로
가며, 무엇은 절대 움직이지 않는가**를 적는다. 코드를 바꾸기 전에 이 선을 먼저 정한다.

앞선 문서를 전제로 한다 — `01-legal-and-privacy.md`(왜 못 내보내는가),
`02-transcription-pipeline.md`(전사 경로), `.claude/skills/provider-routing`(모델 배정).

---

## 1. 왜 바꾸나

세 가지가 겹쳤다.

1. **앱이 AI 배선을 지고 있다.** `llm.ts` 1,020줄 + `pipeline.ts` 1,008줄 +
   설정 화면 855줄 + 채팅 461줄. 모델 판이 바뀔 때마다 앱을 고쳐 새 APK 를 깔아야 한다.
2. **폰은 긴 작업에 안 맞는다.** 배치가 몇 시간 걸리는데 그동안 폰이 깨어 있어야 하고,
   앱이 죽으면 복구 코드로 이어 붙여야 한다(`pipeline_jobs`).
3. **대화는 이미 좋은 것이 있다.** 클로드·GPT 앱이 앱 안 채팅보다 낫다. 앱은 그들이
   못 하는 것(자동 녹음·듀티·금고·사전 교정)만 하면 된다.

---

## 2. 세 자리

| 자리 | 갖는 것 | 안 갖는 것 |
| --- | --- | --- |
| **폰 (앱)** | 자동 녹음, 듀티표, 티로 노트 가져오기, 병동 사전 교정, 카드 복습, **원본 금고**, **마스킹** | 모델 선택, API 키, 채팅, 배치 폴링 |
| **VPS** | 심층 분석 파이프라인(클로드 코드 + 스킬), MCP 창구 | **원본 전사본, 오디오** |
| **대화 AI** | 대화, 조사, 설명, 사전에 새 용어 쓰기 | 전사본 원문 읽기, 오디오, 태움 원자료 |

핵심 한 줄: **원본과 오디오는 폰을 떠나지 않는다. 떠나는 것은 마스킹을 통과한 사본뿐이다.**

---

## 3. 데이터가 움직이는 길

```
        ┌─────────────────────────── 폰 (앱) ───────────────────────────┐
        │ 녹음 ─▶ 티로 전사 가져오기 ─▶ 사전 교정 ─▶ 금고(SQLite)        │
        │                                              │                │
        │                                     deidentify (필수 관문)     │
        └──────────────────────────────────────────────│────────────────┘
                                                       │ HTTPS + 토큰
                                                       ▼
        ┌───────────────────────────── VPS ────────────────────────────┐
        │ 마스킹된 근무 꾸러미 ─▶ 파이프라인(3a·3v·3b·4) ─▶ 보고서·카드 │
        │                                   ▲                          │
        │                              MCP 창구 (인증 필수)             │
        └───────────────────────────────────│──────────────────────────┘
                                            │
                                     대화 AI (클로드·GPT 앱)
```

되돌아오는 길: 보고서·카드는 폰이 VPS 에서 받아 금고에 넣는다. 카드 복습 기록은
폰에만 있다.

**분석은 평소 쓰는 채팅 안에서 돈다.** 클로드·GPT 앱에 VPS 를 **커넥터**로 붙이면
(원격 MCP), 평소 대화 세션에 도구가 생긴다. "9월 3일 근무 분석해줘"라고 하면 그
세션의 AI 가 도구로 자료를 읽고 분석해 결과를 다시 도구로 써 넣는다. 앱 안에
채팅을 만들지 않는 이유가 이것이다.

분석 규칙은 이미 이 저장소의 스킬에 있다 — `nursing-pipeline`(단계 순서),
`pipeline-schema`(출력 스키마 정본), `korean-clinical-style`(문체). VPS 는 이
규칙을 **MCP 프롬프트**로 함께 내보내, 대화가 시작될 때 AI 가 순서를 알게 한다.

**대신 자동 실행은 없다.** 커넥터는 사람이 말을 걸어야 도는 통로다. 밤에 저절로
도는 분석을 원하면 그때 VPS 에 CLI(클로드 코드 등)나 API 를 더한다 — 지금은 안 한다.

**절대 이 길로 안 가는 것**

- 오디오 파일 (마스킹이 불가능하다 — `01` 문서 참조)
- `rawText`(ASR 원문)와 교정 전 문장
- 마스킹 되돌리기용 원문 (`Redaction.original`)
- 화자 실명, 등록번호, 병실, 위치 기록
- 태움 점수를 만든 문장. 숫자와 추세만 나간다

## 4. 마스킹 계약

**가리는 자리는 폰이다.** 서버에서 가리려면 원문이 서버로 가야 하고, 그러면 가리는
의미가 없다. `packages/core/src/transcription/deidentify.ts` 가 그 자리다(테스트 18개).

| 가리는 것 | 주민번호 · 전화번호 · 등록번호 · 이름(호칭 추정) · 생년월일 · 병실 |
| --- | --- |
| **못 가리는 것** | 호칭 없이 부르는 이름("영희야 이거 좀"), **오디오 전체** |

- 저장할 때는 가리지 않는다. 원본은 증거다 — 나갈 때만 가린다.
- 사용자가 등록한 이름은 `extraTerms` 로 함께 가린다. **그래서 병동 사전을 지우면 안 된다.**
- 파이썬으로 한 번 더 훑고 싶으면 VPS 에서 **2차 검문소**로 쓴다. 1차를 대체하지 않는다.
  (안드로이드 앱 안에서는 파이썬이 돌지 않는다. 얹으면 APK 가 커지고 빌드가 깨진다.)

## 5. VPS 규칙

새로 생기는 위험은 하나다 — **쌓인다.** AI 로 가는 것은 어차피 나가지만, 서버에
남은 것은 계속 남는다. 그래서 다섯 가지를 지킨다.

1. **마스킹을 통과한 것만 올린다.** 폰이 관문이고 서버는 검사하지 않는다고 가정하지 않는다.
2. **무한 보관한다(정함).** 지우지 않기로 했으므로 그 대가를 다른 데서 갚는다 —
   디스크 암호화, SSH 열쇠만 허용(비밀번호 로그인 끔), 443 말고는 다 닫기,
   백업도 암호화. 쌓인 만큼이 사고 시의 크기다.
3. **MCP 는 인증 없이 열지 않는다.** 토큰 또는 OAuth. 열어 두면 인터넷 전체가 읽는다.
4. **로그에 본문을 남기지 않는다.** 오류 로그에 전사본이 섞이는 것이 가장 흔한 유출이다.
5. **API 키는 서버 환경변수에.** 저장소·이미지·로그에 넣지 않는다.

덧: 리전은 국내를 권한다. 백업을 켜면 백업도 암호화한다.

## 6. MCP 도구 — 여는 것과 안 여는 것

도구를 넓게 열면 규칙이 한 번에 무너진다. 도구 하나가 곧 문 하나다.

| 여는 도구 | 무엇을 준다 |
| --- | --- |
| `list_shifts` | 날짜·듀티·근무 시간·전사 여부 |
| `get_shift_report` | 마스킹된 근무 보고서 |
| `search_terms` | 병동 사전 항목·뜻 |
| `add_term` | 사전에 새 용어 쓰기 (대화 AI 가 배운 것을 넣는다) |
| `get_cards` / `add_card` | 학습카드 읽기·만들기 |
| `get_taeum_summary` | 점수와 추세 **숫자만** |

| 안 여는 도구 | 왜 |
| --- | --- |
| 전사본 원문 읽기 | 하나로 8시간 병동 대화가 통째로 나간다 |
| 오디오 내려받기 | 목소리는 가릴 수 없다 |
| 화자 이름·병실·등록번호 | 가명정보도 개인정보다 (`01` 문서) |
| 태움 원자료 문장 | 사람이 특정된다 |

## 7. 모델 배정 — 구독제 전제

**API 종량제를 쓰지 않는다.** 구독으로 쓴다. 이것이 배정의 전제를 바꾼다.

| | API 였을 때 | 구독일 때 |
| --- | --- | --- |
| 비용 | 토큰만큼 (배치 50% 할인) | 정액. 추가 비용 없음 |
| 여러 회사 쓰기 | 키만 넣으면 됨 | **구독을 두 개 들어야 함** |
| 배치 API | 씀 | 못 씀 (API 전용) |
| 한도 | 요금이 한도 | 주간 사용량 한도 |

`provider-routing` 스킬의 규칙(근거 없이 배정을 바꾸지 않는다)은 그대로다.
구독제는 그 근거를 바꾸는 **새 사실**이므로, 다음과 같이 좁힌다.

**한 회사만 쓴다(정함).** 클로드 또는 GPT 중 하나. 구독 하나로 끝낸다.

그래서 **교차 검증을 포기한다.** 이 문서에 적어 둔다 — 조용히 사라지게 두지 않는다.
포기하면 잃는 것은 이것이다.

- 3v 검증이 **자기 채점**이 된다. 자기가 뽑은 항목을 자기가 맞다고 할 확률이 는다.
- 특히 위험한 자리는 **3b 조사**(웹에서 근거를 찾는 단계)다. 억지 추정이 그대로 통과할 수 있다.

그래서 다음 두 가지로 대신 막는다.

1. **기계 검증을 먼저 돌린다.** 원문 인용이 실제 전사본에 있는지, source_id 가
   실재하는지는 모델이 아니라 코드가 본다 (`pipeline-schema` 규칙).
2. **모델을 자리마다 다르게 쓴다.** 같은 회사 안에서도 추출과 검증을 다른 모델에
   맡긴다. 같은 계열이라 효과는 줄지만, 같은 대화 안에서 자기가 자기를 승인하는
   것보다는 낫다.

나중에 검증만 다른 회사의 싼 API(제미나이 플래시 같은)로 되돌릴 여지는 남겨 둔다.
한 달 몇백 원짜리 자리이므로, 보고서를 믿기 어려워지면 그때 다시 켠다.

### 구독으로 돌릴 때의 제약

- **한도가 요금이 아니라 사용량이다.** 8시간 근무 전사본은 길다. 한 판에 다 못
  돌리면 근무를 나눠 며칠에 걸쳐 돌린다. 실패가 아니라 대기다.
- **웹 화면을 자동으로 조작하지 않는다.** 구독을 코드로 쓰는 정식 길은 CLI 로
  로그인해 쓰는 것이다. 브라우저를 흉내 내 긁는 방식은 약관 위반이고 금방 막힌다.
- **배치 할인이 없다.** 대신 종량 요금 자체가 없다.

## 8. 앱에서 지우는 것 / 남기는 것

| 지운다 | 남긴다 |
| --- | --- |
| 채팅 화면 (`care.tsx`) | 자동 녹음·듀티·근무 기록 |
| 모델 선택·API 키 화면 (`models.tsx` 대부분) | 티로 열쇠 넣는 칸 하나 |
| `llm.ts` 의 대화·모델 라우팅 | 티로 노트 가져오기 |
| `pipeline.ts` 의 배치 폴링·복구 | **병동 사전과 교정** (연료다) |
| 단어장 **화면** | 사전 **데이터** — 입력은 AI 가 MCP 로 한다 |
| | 학습카드·복습 주기 |
| | `deidentify` (마스킹 관문) |

지워지는 코드 2,000줄 안팎, 새로 만드는 VPS 쪽 300~400줄로 본다.

## 9. 옮기는 순서

한꺼번에 바꾸면 전부 깨진다. 각 단계는 그 자체로 쓸 수 있는 상태여야 한다.

1. **VPS 뼈대** — HTTPS + 인증 + 도구 두 개(`list_shifts`, `search_terms`).
   클로드(또는 GPT) 설정에서 커넥터로 붙여, 평소 채팅에서 도구가 보이는지까지 확인한다.
   폰은 아직 안 건드린다. 손으로 만든 꾸러미 하나로 끝까지 돌려 본다.
2. **올리는 길** — 앱에 "이 근무 보내기" 하나. 마스킹 통과본만. 지금 파이프라인은 그대로 둔다.
3. **파이프라인 이사** — VPS 에서 돌리고 결과를 폰이 받는다. 앱 쪽 파이프라인은
   **한 판 더 남겨 둔다** (되돌릴 자리).
4. **앱 덜어내기** — 채팅·모델 화면·`llm.ts` 정리. 사전 데이터는 남긴다.
5. **사전 쓰기 도구** — `add_term` 을 열고 단어장 화면을 지운다.

## 10. 정한 것 (2026-09-05)

| 항목 | 정한 것 |
| --- | --- |
| 대화 상대 | 앱 안 채팅이 아니라 **평소 쓰는 클로드·GPT 앱**. VPS 를 커넥터로 붙인다 |
| AI 회사 | **하나만** (클로드 또는 GPT). 교차 검증은 포기하고 기계 검증으로 대신한다 |
| VPS 보관 | **무한 보관.** 대신 암호화·접근 제한을 조인다 |
| 폰 → VPS | 앱 설정에 **서버 주소와 토큰을 미리 넣어 둔다** (티로 열쇠와 같은 자리) |
| MCP 인증 | **OAuth.** 커넥터가 그것만 받는다. 주소는 비밀이 아니고, 연결할 때 로그인 화면에서 열쇠를 한 번 넣는다 |
| 앱 채팅 | **뺀다** |

## 11. 아직 안 정한 것

- 클로드냐 GPT 냐 (커넥터 붙이는 방법이 조금 다르다)
- 도메인을 붙일지, IP + 인증서로 갈지

## 12. VPS 에 미리 준비할 것

서버 프로그램은 아직 없다. 그전에 이것만 준비해 두면 붙이는 날 바로 된다.

1. **우분투 계열 서버 하나.** 램 1GB면 충분하다 — 무거운 계산은 AI 쪽에서 한다.
2. **도메인 하나** (없으면 무료 도메인도 된다). 커넥터는 **https 만** 받는다.
   IP 만으로는 인증서를 못 받아 붙지 않는다.
3. **443 만 열고 나머지는 닫기.** SSH 는 열쇠 로그인만, 비밀번호 로그인은 끈다.
4. **caddy 또는 nginx** — 인증서를 자동으로 받아 준다. caddy 가 설정이 한 줄이다.
5. **파이썬 3.11 이상.** MCP 서버를 파이썬으로 쓴다.
6. 디스크 암호화를 켤 수 있으면 켠다. 무한 보관이라 이게 마지막 방벽이다.

여기까지 되면 서버 프로그램을 올리고, 클로드(또는 GPT) 설정에서 커넥터 주소를
넣고, 앱 설정에 같은 주소와 토큰을 넣는다.

---

이 문서의 결정이 코드로 옮겨지면 `nsr-privacy` 스킬에 VPS 절을 더한다 — 나가는
길이 하나 늘었으므로, 그 규칙도 스킬에 적혀야 한다.
