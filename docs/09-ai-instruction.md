# 분석 AI 지침 — 근거

전사본을 읽고 보고서·카드·교정을 만드는 쪽(클로드·GPT)에 넣는 지침의 근거다.
지침 본문은 [`docs/ai-instruction.md`](ai-instruction.md) 한 파일이다.

지침은 **지금 있는 도구로 실제로 할 수 있는 것만** 시킨다. 못 하는 것을 시키면
AI 가 했다고 말하고 아무 일도 안 일어난다 — 그게 이 프로젝트에서 가장 자주 난 사고다.

## 지금 되는 것과 안 되는 것

| 사용자가 원한 것 | 지금 | 어떻게 |
| --- | --- | --- |
| 1. 전사본이 들어오면 알아서 동작 | 안 됨 | **사람이 말을 걸어야 한다.** 아래 참고 |
| 2. 화자 가리기 (본인·선배·의사·환자) | 됨 | `set_speaker_roles` 로 넘기면 폰이 가져가 전사 화면의 이름표를 바꾼다 |
| 3. 전사 교정 → 확정 → 단어장·전사본 반영 | 됨 | 단어장은 `add_term`(티로 단어장까지), 문장은 `put_corrections` 로 폰이 교정본을 고친다. **원문은 안 바뀐다** |
| 4. 보고서 · 카드세트 · 복습 | 됨 | `put_shift_report` 한 장에 다 담는다. 폰이 '결과 받기' 로 가져간다 |
| 5. 근무 체온(태움) 분석 | 됨 | 문장이 전부 와 있다. **AI 가 문장 하나하나 읽고 판단한다.** `get_taeum_summary` 는 앱의 규칙 기반 점수라 맞대 보는 용도다 |

1번만 안 된다. 아래에 왜인지 적었다.

## 1번 — 왜 자동 발동이 아닌가

앱 → VPS 까지는 이미 밀어 넣는 방식이다(전사본을 가져오면 그 자리에서 올라간다).
막히는 곳은 **VPS → 대화 AI** 구간이다. 대화 AI 에는 바깥에서 깨울 문이 없다.
깨우려면 VPS 가 앤트로픽 쪽을 찔러야 하고, 그러려면 **VPS 에 API 토큰을 둬야
한다** — 이 프로젝트가 없애려고 애쓴 바로 그것이고, 그 토큰이 새면 계정 전체가 열린다.

되풀이 일정(하루 몇 번 깨어나 새 근무를 찾는 것)은 걸 수 있지만, 4단계 교정이
**사람의 확정을 받아야** 넘어가므로 어차피 사람이 대화를 연다. 그래서 지침은
**대화로 진행하는 꼴**로 쓴다 — 사람이 말을 걸면 그때 한 단계씩 움직인다.

일정을 걸고 싶어지면 지침을 바꿀 필요는 없다. "1시간마다 새 근무가 있으면 3단계
까지만 해 두고 기다려" 라고 시키면 된다.
