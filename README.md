# NSR — 신규간호사 근무 기록·학습 앱

근무 중 들은 것을 붙잡아두고, 그걸 학습자료로 바꾸고, 근무 환경을 기록해두는 앱.

신규간호사에게 실제로 일어나는 일은 이렇다. 인계에서 처음 듣는 말이 쏟아지고,
못 알아들은 채로 넘어가고, 근무가 끝나면 뭘 들었는지 흐릿해진다.
다음 근무에 같은 말이 또 나오고 같은 자리에서 또 막힌다.
그 사이 어떤 말을 들었는지도 기억나지 않고 "내가 예민한 건가"라는 자기 의심만 남는다.

이 앱은 그 흐릿함을 붙잡는다.

## 먼저 알아야 할 것

**요구사항 1번 "폰에서 티 안 나게"는 절반만 가능하다.**
iOS 14+와 Android 12+는 마이크 사용 표시를 OS 레벨에서 강제하며 앱이 끌 수 있는 API가 없다.
앱이 만드는 소리·진동·알림은 전부 없앨 수 있지만, OS 표시는 남는다.

**8시간 통째 녹음은 법적 위험이 있다.**
통신비밀보호법은 "공개되지 아니한 **타인간의** 대화" 녹음을 금지한다.
내가 참여한 대화는 괜찮지만, 폰을 두고 자리를 비운 사이 남들끼리 나눈 대화가 녹음되면
그건 벌금형이 없는 범죄다(1년 이상 징역). 그래서 앱은 **본인 음성이 없는 구간을 자동으로 버린다.**

**병원 내규는 별개다.** 법을 어기지 않아도 취업규칙 위반으로 징계 사유가 될 수 있다.

자세한 내용: [docs/01-legal-and-privacy.md](docs/01-legal-and-privacy.md)

## 구조

```
packages/core/     플랫폼 비의존 도메인 로직 (테스트 109개)
  hangul/          자모 분해, 음운 변동, 가중 편집거리, 약어 복원
  lexicon/         간호 용어 · 병동 은어 사전
  transcription/   Whisper 프롬프트 생성, 후처리 교정, 사용자 학습, 비식별화
  taeum/           괴롭힘 유형 탐지와 지표
  study/           학습카드 생성, SM-2 간격반복, 근무 보고서
  duty/            듀티표, 녹음 구간, 근로시간 지표
  sources/         공식 자료 레지스트리

apps/mobile/       Expo(React Native) 앱
  app/             화면 (expo-router)
  src/db/          SQLite
  src/services/    녹음 · 스케줄러 · ASR · LLM

docs/              법적 검토, 전사 원리
```

핵심 로직이 `packages/core`에 몰려 있고 플랫폼 API를 전혀 모른다.
그래서 전부 단위 테스트로 검증되며, 앱 코드는 화면과 저장만 담당한다.

## 실행

### 코어 (테스트·타입체크)

```bash
npm install
npm test          # vitest 109개
npm run typecheck
```

### 앱

Expo Go에서는 온디바이스 전사(네이티브 모듈)가 동작하지 않는다. 개발 빌드가 필요하다.

```bash
cd apps/mobile
npm install
npx expo install --fix        # SDK 버전에 맞춰 의존성 정렬
npx expo run:ios              # 또는 run:android
```

온디바이스 전사를 쓰려면 whisper.cpp 바인딩을 추가한다.

```bash
npx expo install whisper.rn
npx expo prebuild
```

## 설계에서 양보하지 않은 것

**원본을 덮어쓰지 않는다.**
`rawText`(ASR 원문)와 원본 오디오는 어떤 경우에도 보존된다. 모든 교정은 별도 레코드로 남고
개별 수락/거절이 가능하다. 편집된 파일만 남은 기록은 증거로서 값어치가 없다.

**말한 내용과 표기를 구분한다.**
"카데타 → 카테터"는 음성인식 오류 교정이므로 고친다.
"폴리 → 유치도뇨관"은 화자가 실제로 한 말을 바꾸는 것이므로 **안 고친다.**
대신 주석을 달아 뜻을 보여주고 학습카드를 만든다.

**점수보다 인용문.**
태움 지표는 판정이 아니다. 어조·표정·맥락은 텍스트에 남지 않는다.
화면은 점수를 작게, 실제로 들은 문장을 크게 보여준다.

**기본값은 기기 안.**
전사·분석은 온디바이스가 기본이다. 외부 전송은 전부 옵트인이고,
켤 때 비식별화가 자동 적용되며 의료법 제19조를 다시 고지한다.

**보관하지 않는 것도 기능이다.**
기간이 지난 녹음은 자동으로 지운다. 오래된 녹음을 쌓아두는 것이
이 앱에서 가장 큰 개인정보 위험이다.

## 아직 안 된 것

- **화자분리 온디바이스 구현** — 인터페이스와 데이터 모델은 준비됐지만
  실제 임베딩·클러스터링 모델은 붙이지 않았다. 지금은 ASR 엔진이 화자 정보를 주면 쓰고,
  없으면 사용자가 직접 라벨을 붙인다.
- **본인 음성 등록·자동 식별** — 설정 항목과 폐기 로직의 자리는 있으나 판정기가 없다.
  이게 붙기 전까지는 사용자가 기기를 몸에 지니는 것으로만 위험을 관리해야 한다.
- **whisper.cpp 실기기 검증** — 어댑터는 작성했으나 실제 기기에서 돌려보지 않았다.
  `apps/mobile/src/services/asr.ts`의 SDK 호출부는 설치된 버전에 맞춰 확인이 필요하다.
- **은어 사전의 지역차** — 내장 사전은 널리 통용되는 표현 위주다.
  병동 고유 표현은 사용자 사전으로 채우게 되어 있고, 사용자 교정이 쌓이면 자동 제안된다.
